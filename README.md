# HR 운영 리포트

인사 시스템 추출 데이터(수업용 합성 데이터)를 브라우저 안의 DuckDB-WASM에 올려 두고 인력 · 근태 · 인건비를 조회하는 앱입니다. 메뉴는 정기 리포트 · HR 모니터링(운영 현황 · 검토 항목 · 조치 현황) · 직접 조회 · 데이터 구조 · 파일 업로드입니다.

## 쓰기 전에

1. 이 앱은 데이터를 브라우저 안에서 읽는다. 올린 파일은 서버에 저장되지 않는다
2. AI에는 질문 · 테이블 설명 · 집계 결과(최대 50행)만 간다. 원본 행은 가지 않는다
3. AI가 쓴 SQL은 실행 전에 읽어 보고, 결과 숫자 하나는 직접 검산한다
4. 올린 파일의 «읽은 행 수»와 «올라간 행 수»가 다르면(✕) 그 결과를 믿지 않는다
5. 파일 이름이 같으면 나중에 올린 파일이 앞의 것을 대신한다

## 운영 모니터링 (로컬 데모)

- **운영 현황 · 검토 항목 · 조치 현황**은 `employees` · `attendance` · `payroll` 세 파일만 씁니다. 근태 · 급여는 직원 · 월 단위로 먼저 집계한 뒤 직원 정보에 연결합니다.
- 검토 항목은 설정한 기준에서 벗어난 **확인할 근거**이며 위반이나 직원의 문제를 판정하지 않습니다. 기본 기준은 모두 **시범 기준**입니다(예: 월 초과근로 30시간은 법정 한도 · 회사 규정이 아님).
- 부서는 `employees.dept`(현재 부서) 기준입니다. 조직 이동 이력이 없어 과거 월의 실제 소속과 다를 수 있습니다.
- 개인별 급여 금액은 대시보드 · 검토 목록 · 상세 화면에 표시하지 않습니다.
- **조치 기록과 검토 기준은 이 브라우저의 localStorage에만 저장됩니다.** 인증 · 권한 · 서버 저장이 없으므로 회사의 공식 조치 이력이 될 수 없습니다. 실제 운영 설계는 [docs/운영_설계안.md](docs/운영_설계안.md)를 보세요.
- 조치 상태는 미확인 · 확인 중 · 조치 중 · 종결 네 가지입니다(이전 기록의 '조치 예정'은 '조치 중', '조치 완료'는 '종결'로 변환하고 원래 값은 `legacyStatus`에 보존).
- **급여 상세 잠금(비밀번호 `edata9`)은 가상 데이터 시연용 화면 잠금입니다.** 비밀번호가 브라우저 코드에 들어 있고, 정기 리포트 · 직접 조회 · 원본 CSV로 같은 데이터를 볼 수 있으므로 실제 접근 통제나 개인정보 보호 기능이 아닙니다.
- 실제 직원 데이터로 인사 조치나 불이익을 결정하는 데 쓰지 마세요.

## 내 PC에서 실행

1. `.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY=` 뒤에 키를 넣습니다. `.env`는 git과 배포에서 빠집니다.
2. `python tools/serve.py` → http://localhost:8780

## Vercel 배포

- 저장소를 Vercel에 연결하면 정적 파일(`index.html` · `js/` · `css/` · `data/` · `schema.json` · `questions/`)과 Python 함수(`api/ask.py`)가 그대로 배포됩니다.
- Vercel 프로젝트 설정 → Environment Variables에 `GEMINI_API_KEY`(필수)와 `GEMINI_MODEL`(선택, 기본 `gemini-3.5-flash-lite`)을 넣습니다.
- `tools/` · `.env` · `다음달/`은 `.vercelignore`로 배포에서 뺍니다.

## 파일

| 경로 | 하는 일 |
|---|---|
| `schema.json` | AI에 보내는 테이블 설명(그레인 · 행 수 · 컬럼 · 지표 정의 · 회사 규칙). `docs/데이터_사전.md` 기준 |
| `questions/prepared.json` | 검증한 준비된 질문과 SQL |
| `js/guard.js` · `api/_sqlguard.py` | 읽기 전용 SQL 검사(같은 규칙) |
| `js/db.js` | DuckDB-WASM 적재 · 실행 |
| `js/metrics.js` | 운영 현황 · 탐지 규칙 · 직원 상세 SQL (세 테이블만 사용) |
| `js/detect.js` | 검토 기준으로 탐지 SQL 실행 → 검토 항목 |
| `js/store.js` | 검토 기준(버전 · 이력) · 조치 기록 — localStorage 로컬 데모 |
| `js/ops.js` · `js/review.js` · `js/actions.js` | 운영 현황 · 검토 항목 · 조치 현황 화면 |
| `js/charts.js` | SVG 차트(선 · 막대 · 가로 막대) |
| `docs/운영_설계안.md` | 실제 운영을 위한 DB · 인증 · 권한 설계안 |
| `api/ask.py` · `api/_llm.py` | Gemini 호출(Vercel 함수) |
| `tools/serve.py` | 내 PC용 서버(화면 + api) |
